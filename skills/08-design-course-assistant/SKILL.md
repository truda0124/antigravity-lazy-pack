# 設計群科教學教案、學習單與極簡時尚簡報全流程助手

## Purpose

結合「設計名師 (#29)」、「設計大師教學教案 (#30)」與「簡報大師 (#27)」三個 Gem，從設計群科課程指導出發，生成結構化教案、組員互動學習單、課堂評量單元試題，並無縫提煉重構為極簡時尚風格的簡報大綱與投影片規格。

## Triggers（核心觸發詞）

- **教學備課類**：`備課`、`寫教案`、`課程規劃`、`教學目標`
- **教材學習單類**：`學習單`、`隨堂練習單`、`手繪練習單`
- **測驗評量類**：`出單元試題`、`隨堂測驗`、`單元考題`、`評量試題`
- **簡報企劃類**：`做簡報`、`教學簡報`、`簡報大綱`、`極簡時尚簡報`

## Workflow

1. 接收使用者輸入之教學主題、課本章節或備課需求（包含觸發詞：「備課」、「寫教案」、「做簡報」、「學習單」、「出單元試題」）
2. 讀取並分析教材核心概念與設計技能要點（如色彩學、造型原理、數位繪圖等）
3. 規劃教學目標、生活案例與分組互動流程（分組討論、互評或共同創作）
4. 產出結構化設計科教案、學生隨堂填空/手繪練習單，或設計群單元評量試題（選擇題/問答題/實作手繪題）
5. 將教學內容提煉重構為極簡時尚風格的簡報架構（封面、目錄、內容頁、感謝頁）與每頁視覺規劃
6. 輸出 Markdown 檔案至 output/ 資料夾，並可選匯出為實體 Word 與 PowerPoint 檔案

## Upgraded capabilities

- 支援直接讀取本地教材檔案（PDF、Word、Markdown 或純文字筆記）
- 一鍵輸出結構化 Markdown 教案、隨堂互動學習單、單元試題以及每頁簡報企劃書
- 可透過 Python 自動產出排版完成的實體 Word (.docx) 與 PowerPoint (.pptx) 文件
- 具備教案結構完整性與簡報視覺規格的自動驗證機制

## Output

在 output/ 目錄下產出完整的教案、學生學習單、單元試題與極簡時尚簡報企劃文件，並提供結構驗證報告。

## Safety
